Fontes dos dados

O itbidata utiliza dados públicos disponibilizados por órgãos municipais. A disponibilidade e o período podem variar de uma cidade para outra.

CidadeFonteObservação
Porto Alegre — RSPortal oficial de dados abertos do municípioRegistros de ITBI disponibilizados em arquivos por período.
Fortaleza — CEPortal oficial de dados abertos do municípioBase municipal com estrutura própria.
São Paulo — SPPortal oficial de dados abertos do municípioBase municipal com estrutura própria e períodos disponíveis conforme publicação.
Belo Horizonte — MGPortal oficial de dados abertos do municípioBase municipal com estrutura própria.
Recife — PEPortal oficial de dados abertos do municípioBase municipal com estrutura própria.

Sobre os links oficiais

As URLs específicas das bases podem mudar conforme a estrutura dos portais municipais. O itbidata deve manter, sempre que possível, a referência à página oficial de origem e ao período do arquivo utilizado.

Licença e atribuição

Quando a fonte original disponibilizar os dados sob licença aberta, a reutilização no itbidata respeita as condições da licença aplicável, incluindo atribuição quando exigida.
